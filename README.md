The program (`main.ts`) writes a single line — the message a smart fridge sends its owner at 3am — to `/output/entry.txt`. The line is 111 characters, inside the 140-character gate.

> 3am. The cheese has been in here longer than your last relationship, and unlike him, it still shows up for you.
